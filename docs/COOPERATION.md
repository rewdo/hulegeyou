## 一、项目简介

### 1.1 定位

《忽了个悠》是一款面向青少年及社会大众的反诈科普微信小游戏。通过"游戏化学习"的方式，让玩家在沉浸式场景中识别各类电信网络诈骗，掌握防范技能。

**一句话定位：** 一款能让年轻人"玩着学反诈"的科普游戏。

### 1.2 核心目标

| 目标维度 | 具体内容 |
|---------|---------|
| **知识普及** | 覆盖 6 大诈骗类型、30+ 真实案例场景，让玩家在游戏中记住防骗要点 |
| **行为改变** | 通过风险判断训练，培养玩家"遇事多方核实、不轻信、不转账"的思维习惯 |
| **社会传播** | 利用微信社交裂变机制，以趣味方式带动反诈知识在亲友间传播 |
| **数据支撑** | 客观记录玩家对各类诈骗的判断准确率，为反诈宣传策略提供数据参考 |

### 1.3 覆盖人群

| 层级 | 目标用户 | 触达方式 |
|------|---------|---------|
| **核心** | 大学生/高职生（18-25 岁） | 校园推广、朋友圈分享 |
| **扩展** | 中青年上班族（25-40 岁） | 社区推广、便民公众号联动 |
| **辐射** | 中老年群体（40 岁以上） | 子女推荐、社区反诈活动 |

## 二、社会价值分析

### 2.1 为何需要反诈游戏

**数据背景：**
- 全国每年电信网络诈骗案件数十万起，涉案金额数百亿元
- 18-30 岁青年群体已成为受骗重灾区（占受骗人数的 40%+）
- 传统反诈宣传（横幅、传单、讲座）对年轻人触达率低、记忆效果差
- 游戏化学习相比传统宣讲，知识留存率提升 3-5 倍（学习金字塔理论）

### 2.2 《忽了个悠》的社会效益

| 维度 | 效益说明 |
|------|---------|
| **预防前移** | 在用户遭遇真实诈骗前完成风险教育，从源头减少受骗可能 |
| **认知训练** | 反复判断训练形成"风险肌肉记忆"，真实场景下快速警觉 |
| **传播裂变** | 社交分享机制让反诈知识像游戏一样自发传播，降低宣教成本 |
| **数据反哺** | 用户的判断数据可反馈给反诈部门，辅助识别重点防范场景 |

### 2.3 数据验证

游戏内置的 30+ 风险事件均基于真实案例改编，覆盖公安部公布的 6 大诈骗类型。每完成一个事件，玩家需要完成：
1. 风险等级判断（安全/低风险/高风险）
2. 阅读对应反诈科普知识
3. 完成验证题目（巩固记忆）

**效果评估指标可量化：**

| 指标 | 定义 | 参考目标 |
|------|------|---------|
| 科普覆盖数 | 完成科普阅读的玩家数 | — |
| 平均判断准确率 | 所有玩家在所有事件上的平均正确率 | 首玩≥60%，复玩≥85% |
| 知识点掌握度 | 验证题答对率 | ≥90% |
| 分享传播系数 | 平均每个用户带来的新用户数 | ≥1.5 |

## 三、技术优势

### 3.1 游戏化学习（优势矩阵）

| 对比项 | 传统宣传 | 传统宣传游戏 | 数字反诈游戏 |
|--------|---------|-------------|-------------|
| 沉浸感 | 低 | 中（线下互动式） | 高（剧情导向） |
| 触达效率 | 低（被动等待） | 低（场地限制） | 高（微信即点即玩） |
| 知识留存率 | ~20% | ~50% | ~75%+ |
| 数据跟踪 | 无 | 人工统计 | 全链路数字化 |
| 可复制性 | 差 | 差 | 强（一键部署） |
| 成本 | 高（印刷/场地/人力） | 高 | 低（在线免物流） |

### 3.2 技术架构

```
玩家 ←→ 微信小游戏 ←API→ Node.js 后端 ←→ MySQL 数据库
                          ↑
                      Nginx 反向代理（HTTPS）
                          ↑
                    腾讯云/阿里云服务器
```

**关键技术指标：**

| 指标 | 数值 |
|------|------|
| 首屏加载 | <3 秒（包体 <2MB） |
| API 响应 | <200ms |
| 并发支持 | 2000+ QPS（单台服务器） |
| 数据库 | MySQL 8.0，支持水平扩展 |
| 安全 | HTTPS 全链路加密 |
| 适配 | 微信小游戏基础库 2.2.3+，iOS/Android |

### 3.3 可定制能力

- **事件库灵活扩展**：运营人员通过 SQL/Excel 批量导入，零代码添加新诈骗案例
- **关卡配置化**：场景、难度、奖励参数可动态调整
- **文案完全可替换**：欢迎页、科普文案、活动通知均支持动态更新
- **合作方数据看板预留**：可定制开发反诈宣传效果数据看板

## 四、合作模式建议

### 模式一：品牌冠名 / 联合出品

> 适合反诈中心、公安部门作为官方反诈科普工具推广

**合作内容：**
- 游戏启动页面添加合作方 Logo 及"联合出品"标识
- 海报/Banner 中标注"XX 反诈中心 × 《忽了个悠》"
- 游戏内科普页面添加权威提示："本内容由 XX 反诈中心指导审核"

**合作方收益：**
- 获得一款可直接投放使用的数字反诈工具
- 微信生态传播，扩大官方反诈宣传覆盖面
- 获取用户反诈认知度数据，指导后续宣教策略

### 模式二：内容共建

> 适合公安、教育部门提供诈骗案例素材

**合作内容：**
- 合作方提供本地高发诈骗案例，我方加工转化为游戏内事件（2 个工作日内完成）
- 合作方审核现有内容准确性，提出修正意见
- 共同开发特定场景主题包（如"开学季反诈""返乡季防骗"）

**合作方收益：**
- 本地化诈骗案例精准触达本地居民
- 借生动游戏形式替代枯燥文件通知

### 模式三：联合推广

> 适合教育局、学校、社区联动

**合作内容：**
- 教育局推荐辖区内学校使用，纳入安全教育课程
- 学校组织反诈主题班会/团日活动，全班集体闯关
- 社区通过便民公众号推送，组织老年人防骗专项游戏

**合作方收益：**
- 零成本获得高质量反诈科普工具
- 量化统计宣教覆盖人数和效果

### 模式四：数据共享

> 适合反诈中心、科研机构进行反诈研究

**合作内容：**
- 定期（月/季）输出用户反诈认知数据报告
- 展示各类诈骗类型的判断准确率、易错点、高发人群画像
- 辅助反诈部门识别宣传教育薄弱环节

**数据范围（脱敏）：**

| 数据类型 | 说明 | 可输出粒度 |
|---------|------|-----------|
| 诈骗类型判断准确率 | 每类诈骗的平均正确率 | 按地区/年龄 |
| 易错事件排行 | 最容易判断错误的事件 | 前 10 名 |
| 用户画像分布 | 活跃用户的年龄/地区分布 | 按日/周/月 |
| 科普阅读率 | 完成科普阅读的用户比例 | 按事件维度 |

> ⚠️ **数据隐私声明：** 所有数据均脱敏处理，不涉及用户身份信息。严格遵守《个人信息保护法》及相关法规。

## 六、典型案例参考

### 案例 1：北京反诈中心 × 支付宝"安全学院"

- **模式**：反诈中心提供专业指导，支付宝开发反诈答题小游戏

### 案例 2：武汉公安 ×"反诈英雄"微信小游戏

- **模式**：公安提供真实案例，游戏公司开发闯关游戏
- **效果**：走进 200+ 所中小学，覆盖学生 15 万+，获央视报道
- **借鉴**：校园推广路径成熟，政府媒体报道放大效应

### 案例 3：深圳南山公安 ×"反诈大侦探"微信小游戏

- **模式**：公安出版反诈内容 + 游戏化互动
- **效果**：趣味推理、典型案例沉浸式体验
- **借鉴**：剧本推理式反诈游戏，契合年轻人的兴趣点

### 案例 4：国家反诈中心"全民反诈"APP 内游戏模块

- **模式**：APP 内嵌入反诈问答/闯关模块
- **效果**：累计 1 亿+ 人次参与，综合反诈率提升
- **借鉴**：将反诈融入高频使用渠道，降低触达门槛

### 案例 5：山东省反诈中心 × 校园"反诈闯关赛"

- **模式**：线上线下联动，高校组织线下活动，配合线上游戏

- **借鉴**：线上游戏 + 线下活动 = 完整体验

## 七、FAQ

### Q1：合作需要我方付费吗？

**A：** 基础合作模式（内容共建 + 联合推广）免费。如需定制开发（专属场景/数据看板/品牌深度包装），视工作量收取技术开发费用。公益合作可协商。

### Q2：游戏目前已经上线了吗？

**A：** 游戏已完成核心开发（前端 + 后端 + 数据库 + 30+ 风险事件），可直接部署上线。当前阶段适合与合作伙伴共同完成上线和推广。

### Q3：如何处理合作中的内容修改？

**A：** 合作方提出的修改意见在 3-5 个工作日内完成。游戏内文案可通过配置化方式实时更新，无需重新提交微信审核。

### Q4：用户数据如何保障安全？

**A：** 游戏仅获取用户的微信 OpenID（匿名标识），不获取微信昵称、头像之外的任何个人信息。运营数据经脱敏后共享，严格遵守《个人信息保护法》。

### Q5：可以支持定制化需求吗？

**A：** 支持。可定制的内容包括：特定诈骗场景主题包、本地化事件、品牌视觉包装、数据大屏、H5 嵌入等。

### Q6：微信小程序合规模块相关问题？

**A：** 游戏内容已过内部审核，不包含暴力、涉黄、赌博等违规内容。反诈科普内容均引用自公开官方资料。合作方可进一步审校。
